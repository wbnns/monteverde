Two Lean statements of P vs NP, proved equivalent.

Let ClayPVersusNP be the LeanMillenniumPrizeProblems formalization of Cook's problem: PΣ = NPΣ for every finite alphabet Σ with |Σ| ≥ 2, over Mathlib's multi-stack machines and Cook's checking relations. Let CslibPEqNP be P(enc) = NP(enc) for every injective binary encoding enc, over cslib-frontier's multi-tape machines. Monteverde proves in Lean 4 that the two propositions are equivalent, using only propext, Classical.choice and Quot.sound. The equivalence is at the level of statements; it does not decide either side.

Quick start

Add Monteverde to lakefile.toml. Your project must use the same toolchain, leanprover/lean4:v4.36.0-rc2. Then run lake update monteverde. More examples are in Using the results.

[[require]]
name = "monteverde"
git = "https://github.com/wbnns/monteverde"
rev = "v1.1.0"
import Monteverde
open Monteverde

example (h : CslibPEqNP) : Millennium.ClayPVersusNP :=
  clay_iff_cslib.mpr h

Definitions

Both sides build on Mathlib. They differ in the machine model, the encoding of instances, and the form of certificates.

Clay (LeanMillenniumPrizeProblems)

Machines are Mathlib's FinTM2: finitely many stacks, finite control, and a finite input alphabet; other stack alphabets are arbitrary types. For a finite Σ and L ⊆ Σ*, L ∈ PΣ iff some FinTM2 decides L within p(|w|) steps, for a polynomial p.

L ∈ NPΣ iff there are a finite Σ1, k ∈ ℕ and R ⊆ Σ* × Σ1* with LR = { w#y : R(w, y) } ∈ P over Σ ⊔ {#} ⊔ Σ1, and w ∈ L ⇔ ∃ y, |y| ≤ |w|k ∧ R(w, y).

ClayPVersusNP :≡ ∀ Σ finite, |Σ| ≥ 2, ∀ L ⊆ Σ*, L ∈ PΣ ⇔ L ∈ NPΣ.

cslib-frontier

Machines are multi-tape Turing machines over {0, 1} with finitely many states. For an injective enc : α ↪ {0, 1}*, f is polynomial-time from enc to enc′ if such a machine computes enc′ ∘ f from enc within polynomially bounded time and space.

A ∈ P(enc) iff 1A is polynomial-time from enc. A ∈ NP(enc) iff there are a polynomial p and a polynomial-time V on encPair(enc, bits) with a ∈ A ⇔ ∃ c ∈ {0, 1}p(|enc a|), V(a, c) = 1.

CslibPEqNP :≡ ∀ α, ∀ enc : α ↪ {0, 1}*, P(enc) = NP(enc). This is the form in which cslib-frontier's own theorems (NPComplete.mem_P_iff) state P = NP.

Results

Write βΓ : Γ* ↪ {0, 1}* for the block code: the symbol of index i maps to (11)i0, and words map to concatenations. All names below are in the namespace Monteverde.

Theorem 1 (functions)

For finite Γ, Δ, injective e : α → Γ*, e′ : β → Δ* and f : α → β: f has a polynomial-time FinTM2 from e to e′ iff f is polynomial-time in cslib-frontier from βΓ ∘ e to βΔ ∘ e′.

tm2_iff_computableInPolyTime_words

Theorem 2 (classes)

For finite Γ with |Γ| ≥ 2 and L ⊆ Γ*: L ∈ PΓ ⇔ L ∈ P(βΓ) and L ∈ NPΓ ⇔ L ∈ NP(βΓ). Polynomial-time many-one reductions correspond in the same way, for any finite alphabets.

clayP_iff_cslib, clayNP_iff_cslib, clayReducible_iff_cslib

Theorem 3 (binary form)

CslibPEqNP ⇔ P(bits) = NP(bits).

cslibPEqNP_iff_bits

Theorem 4 (main)

ClayPVersusNP ⇔ CslibPEqNP, hence also NegativeBranch ⇔ ¬CslibPEqNP.

clay_iff_cslib, clay_negative_iff_cslib

A further lemma has independent interest: every polynomial-time FinTM2 certificate with a finite output alphabet has one with the same function and time bound whose stack alphabets are all finite (TM2ComputableInPolyTime.exists_finite).

Proof sketch

Finite alphabets

FinTM2 requires only the input alphabet to be finite. Every push writes g(σ) for one of finitely many statements g and a state σ in a finite set, so the symbols that can ever reach stack k lie in a finite set Sk. Restricting each stack to Sk ∪ (input symbols) gives a machine with the same run, step for step. cslib-frontier's TM2 bridge then applies.

The reverse direction

A cslib-frontier function becomes a FinTM2 by composing three machines: a recoder Γ* → βΓ(Γ*) (2n + m + 2 steps), cslib-frontier's binary compiler, and a decoder βΔ(Δ*) → Δ* (≤ 7n + 2 steps), joined by Tan's composition theorem for polynomial-time TM2 machines. For empty Δ the only output is ε, and a draining machine suffices.

NP

Clay to cslib-frontier: the verifier decodes a binary certificate as y ∈ Σ1*, checks |y| ≤ |w|k, and runs the Clay checker on w#y; a padding lemma turns a bound into an exact length p(n). Conversely, take Σ1 = {0, 1} and R(w, c) :⇔ |c| = q(|β w|) ∧ V(w, c). As |β w| ≤ (2|Σ| + 1)|w|, there is k with q(|β w|) ≤ |w|k for |w| ≥ 2. The finitely many words with |w| ≤ 1, where |w|k ≤ 1, are decided by table with the empty certificate.

The main theorem

⇒: apply ClayPVersusNP at Σ = {0, 1} to the binary image of SAT. Its NP membership transfers to the Clay side by Theorem 2, the hypothesis puts it in P{0,1}, and Theorem 2 brings it back. Since SAT is NP-complete in cslib-frontier, P(enc) = NP(enc) for every enc. ⇐: for each Σ, use enc = βΣ and Theorem 2.

Using the results

Checked in CI (Tests/ReadmeExamples.lean).

import Monteverde

-- A cslib-frontier proof of P = NP on binary strings gives the Clay statement.
example (h : P encBits = NP encBits) : Millennium.ClayPVersusNP :=
  clay_iff_cslib.mpr (cslibPEqNP_iff_bits.mpr h)

-- A problem in cslib-frontier NP but not in P gives the negative Clay statement.
example {α : Type} (enc : α ↪ List Bool) (A : Set α) (hNP : A ∈ NP enc) (hP : A ∉ P enc) :
    Millennium.ClayPVersusNP.Formulations.NegativeBranch :=
  clay_negative_iff_cslib.mpr fun h => hP (by rw [h enc]; exact hNP)

Relation to Cook's text

The Cook text audit maps each clause of Cook's official problem description to the Lean definitions. The differences that matter:

  • Machine model. Mathlib's multi-stack FinTM2 replaces the one-tape machine. The models simulate each other with polynomial overhead, but no Lean proof of this exists yet.
  • Alphabets. The Lean target quantifies over all Σ with |Σ| ≥ 2; Cook fixes one Σ and remarks that the choice does not matter. The proof of Theorem 4 shows this for the Lean model: the case Σ = {0, 1} already implies all others.
  • Certificate bound. The literal bound |y| ≤ |w|k allows at most one symbol when |w| ≤ 1. It defines the same NP as a polynomial bound.
  • Checking relation. The decider for LR need only be correct on well-formed w#y, a linear-time-checkable promise.
  • P ⊆ NP. The Clay file proves it from a composition hypothesis, which Tan's composition theorem discharges.

Open directions

Monteverde is a stable reference at v1.1.0, released under Apache 2.0. The way to extend it is a fork: no permission is needed; please keep NOTICE and CREDITS.md.

  • The machine model. A Lean proof that FinTM2 and a one-tape Turing machine simulate each other in polynomial time would close the one gap between Cook's text and the Lean statement.
  • Other formalizations. Bridges of the same kind to the single-tape model of CSLib, or to the definitions of starpos/lean-np-complete.
  • Other classes. coNP, the polynomial hierarchy, or space classes, through the function bridge.
  • Review. An independent review of the Cook text audit by a complexity theorist, published anywhere.
